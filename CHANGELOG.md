# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] - 2026-10-16

### Added

- Конвертер GURPS-долларов в игровые монеты и обратно.
- Таблица броска реакции с наценкой при покупке и скидкой при продаже.
- Ценник по Статусу: ночлег, завтрак/ланч, обед, спиртное, паёк.
- Матрица цен по всем Статусам.
- Настраиваемые валюты (с цветом), категории, статусы и таблица реакции.
- Добавление/удаление строк и перетаскивание для смены порядка в настройках.
- Сброс каждого блока настроек отдельно к значениям по умолчанию.
- Кнопка настроек в окне помощника (только для Мастера).
- Локализации: русский, английский.
